# Mawahib.io

Marketing site for [Mawahib](https://mawahib.app) — the creative talent marketplace for the MENA region.

## Tech Stack

- React 19
- Vite 7
- Deployed via GitHub Pages

## Development

Requires Node 20+.

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

The site is deployed to GitHub Pages at [mawahib.io](https://mawahib.io).

```bash
npm run deploy
```

This builds the project and pushes to the `gh-pages` branch.
